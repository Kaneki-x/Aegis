# Fonts

`app/src/main/res/font/cue_display_*.ttf` are static instances (weights 600,
700 and 800) generated from the Manrope variable font, renamed "Cue Display"
as the SIL Open Font License asks for modified versions. The original is
copyright 2018 The Manrope Project Authors and licensed under the OFL 1.1, see
`OFL-Manrope.txt`.
